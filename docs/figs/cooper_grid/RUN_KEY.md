# Run key — what every simulation in this grid is

Generated by `docs/cooper_basin/make_run_key.py` from the decks in
`grid_search_inputs/` and `grid_scores.json`. Do not edit by hand.

## How to read the two score columns

**front** is λ/λ_obs. λ is the fit of R = λ√t to the slip front, where the
front is the outermost radius with slip > **1e-4 m — a fixed threshold for
every run**, not each run's own `dc`. Scored on **0–5 d**, with the observed
front refit on that same window (λ_obs = 0.1866). 1.00 is a match. A number
without its window is meaningless: these same runs score 0.97–0.99 on 0–8 d.

**wellhead** is mean(sim) / mean(measured) − 1 over **flowing periods only**
(injecting above 25% of peak). Not mean(sim/measured) — the measured wellhead
falls through ~0 during shut-ins, and dividing by that read 2.17 and 0.32 on
two samplings of the same run. 0% is a match; ±15% is the agreed band.

**pk/dc** is peak slip divided by that run's own `dc`. This one *is*
per-run, because it asks a different question — did the patch weaken at all.
Below ~1 there is no front to speak of and the λ is near-noise; `no slip`
means nothing reached the threshold, which is a result, not missing data.

## Column legend

| column | meaning |
|---|---|
| σ̄₀ | `sigmainit`, effective normal stress, MPa |
| τ₀ | `muinit` × `sigmainit`, initial shear stress, MPa. **An initial condition on stress, not a friction coefficient.** |
| Δτc | f₀σ̄₀ − τ₀, how much overpressure a Mohr–Coulomb reading would need. Reported for orientation only — HBI's regularised friction law has no threshold. |
| k near/far | max and min of the initial permeability field, m². The rule: near-well disc **is** `kpmax`, background **is** `kp` = `kpmin`. |
| φ | porosity, as **near-well / far-field**. G1 = 0.020 near, G3 = 0.005 near (the inverse control). A single value means uniform. |
| η | fluid viscosity, Pa·s. 8.9e-4 is Taiyi's (water at 25 °C); 1.27e-4 is this study's, for 4.1 km reservoir conditions |
| pev | `permev` — permeability enhancement on (T) or off (F) |
| ds | cell size, m. **Not constant across the grid** — 5 m for 66 runs, 20 m for the Taiyi pair. |

| | value | |
|---|---|---|
| `f0` | **0.6** | never varied in any of 723 decks — every "friction sweep" here was a τ₀ sweep |
| `a` / `b` | **0.015 / 0.012** | a − b = +0.003, velocity-**strengthening** |
| `dc` | 1e-4 | except 1.53e-5 in 632880 |
| `imax` × `jmax` | 601 × 601 | |
| ~~`ds`~~ | **NOT fixed** | 5 m for 66 runs, 20 m for 632880/632881. The Taiyi pair needs the wider domain because their far-field k gives D = 4.49 m²/s, so at ds 5 m the 5 d diffusion front (2.79 km) would exceed the 1.5 km half-domain. Listed here because this is where someone would look for it. |
| `injection_file` | `june_clean.txt` | rate is per unit fault width, not total well flow — multiply by w = 6 m |
| `rigid`, `Sw_fwid`, `rw` | 24 GPa, 7.4e-9, 8.9e-2 m | |
| `kL` / `kT` | 1e-3 / 1e15 | enhancement slip scale and healing time |

**Consequence of a − b = +0.003:** every run is velocity-strengthening and produces no seismicity. What is being compared is an *aseismic slip front* against an observed *seismicity front*, under the assumption that the slip front does not care whether the slip was seismic.

## Where the grid stands

- Best front: **632875**, λ/λ_obs **1.03**, wellhead +80.0%
- Runs with the wellhead inside ±15%: **27** of 68
- Runs inside **both** bands: **none**

The two targets are in tension: the wellhead needs *low* near-well overpressure, the front needs *high*. τ₀ moves the front without moving the wellhead at all — see Stage 3, where the wellhead is flat to ±0.1% across the whole sweep — but it saturates at λ 0.34 by τ₀ = 15.0, and τ₀ cannot exceed f₀σ̄₀ = 16.79 MPa without the fault being past its own strength at zero overpressure.
